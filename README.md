📊 Sales Data Analysis

📌 Objective
The goal of this project is to analyze sales data and extract meaningful business insights.

🛠️ Tools Used
- Python
- Pandas
- Matplotlib

📂 Dataset
Superstore sales dataset containing orders, regions, categories, and profit.

📈 Key Insights
- Technology category generates the highest sales
- West region shows strong profit performance
- Some categories have high sales but low profit

📷 Visualizations
Graphs showing:
- Sales by Category
- Profit by Region

🚀 Conclusion
This analysis helps understand sales trends and improve business decision
